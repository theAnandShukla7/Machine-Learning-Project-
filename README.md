# Laptop Price Prediction Model

## Project Overview

This project uses Machine Learning to predict the price of laptops based on different features such as brand, RAM, processor, storage, screen size, and other specifications.

The goal of this project is to build a predictive model that helps estimate laptop prices using historical data.

## Features

* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Feature selection and encoding
* Machine Learning model training
* Price prediction based on laptop specifications

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib / Seaborn

## Dataset

The dataset contains different laptop specifications including:

* Brand
* Processor
* RAM
* Storage
* GPU
* Screen size
* Operating system
* Price

## Machine Learning Model

The model is trained using regression algorithms such as:

* Linear Regression
* Random Forest Regressor

These models analyze the relationship between laptop features and their prices.

## How It Works

1. Load the dataset
2. Clean and preprocess the data
3. Perform exploratory data analysis
4. Train machine learning models
5. Evaluate model performance
6. Predict laptop prices

## Future Improvements

* Add more laptop specifications
* Improve model accuracy
* Deploy the model as a web application
